🔥 RGB Gaming Login Page

A modern and stylish RGB Gaming Login Page featuring a premium dark theme, animated rainbow borders, glowing effects, and a smooth gaming-style interface.

🚀 Features

- 🎨 Premium Black & Dark Theme
- 🌈 Animated RGB Rainbow Border
- ✨ Glowing RGB Login Button
- 🔐 Username / Gamertag Input
- 🔑 Password / Passcode Input
- ⚡ Smooth CSS Animations
- 💡 RGB Focus & Hover Effects
- 📱 Responsive Viewport Setup
- 👨‍💻 Clean and Simple UI

🛠️ Technologies Used

- HTML5
- CSS3
- CSS Animations

📋 Login Requirements

1. Username / Gamertag
2. Password / Passcode
3. Access System Button

📂 Project Structure

RGB-Login-Page/
│
└── index.html

▶️ How to Use

1. Download or Clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. Enjoy the RGB Gaming Login Design!

⚠️ Note

This project currently contains the frontend login design only. Authentication, account creation, and database connectivity are not implemented.
